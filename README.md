# mrivals-builder-front

This is the frontend application for the Marvel Rivals Builder project, built with React, TypeScript, and Vite.

## Prerequisites

- **Node.js**: Version 18 or higher is recommended.
- **npm**: Comes with Node.js.

## Installation

1.  Navigate to the project directory:
    ```bash
    cd mrivals-builder-front
    ```

2.  Install dependencies:
    ```bash
    npm install
    ```

## Running Development Server

To start the local development server:

```bash
npm run dev
```

The application will typically run on `http://localhost:5173` (check the terminal output for the exact URL).

## Building for Production

To build the application for production:

```bash
npm run build
```

The build artifacts will be stored in the `dist/` directory.

## Linting

To run the linter:

```bash
npm run lint
```
